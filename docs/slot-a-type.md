# 釣嫁スロット「潮騒パラダイス」Aタイプ

## 実装範囲

オリジナルの5ラインAタイプ。実機ROMや非公開停止テーブルの再現ではない。
参考にしたメーカー公開資料：
- https://www.kitadenshi.co.jp/slot/neoimjugglerex/ （配列・配当・BB/RB）
- https://www.kitadenshi.co.jp/slot/funkyjuggler2/ （配列・配当・BB/RB）

3本それぞれ異なる21コマ配列。上下方向に連続した帯を上から下へ回す。
有効ラインは上・中・下・右下がり・右上がり。7/7/7でBIG、7/7/BARでREG。
左リールのいずれかの段にチェリーがあれば2枚（複数ラインで重複加算しない）。
ベル8枚、フィッシュ6枚、リプレイは次回通常ゲームを無料にする。複数入賞は合算し最大15枚。

## 抽選と状態

通常時の役はリプレイ1/7.3、ベル1/6、魚1/20、チェリー1/40、残りハズレ。
ボーナス未成立の通常時ゲームでは独立してBIG1/180、REG1/240を抽選する。
小役と同時成立も可能。ボーナスは告知し、入賞まで持ち越す。
小役成立時は小役を優先し、そのゲームではボーナスは揃わない。
ボーナス中は新規ボーナス抽選なし。通常3枚、リプレイ次回0枚、ボーナス中1枚。
ボーナス中はベル成立、BIGは累計252枚以上、REGは96枚以上の**払い出し**で終了。
ベルのみならBIG実際の払い出しは256枚（32G、差枚224枚）、REG96枚（12G、差枚84枚）。
取りこぼしがあればゲーム数・純増が変わる。実機の規格を再現した値ではない。
通常合算の表示分母は通常ゲーム数、総ゲーム数はボーナス中も含む。
ART、上乗せ、天井、ハマリ補正、設定変更はない。

## 停止制御

押した瞬間の帯位置を凍結し、その次の停止境界から0〜4コマ先の候補を探す。
端数分の境界移動を含む実移動は5コマ未満。全周回して合わせることはしない。
押し順不問。既停止リールを固定し、5ライン全体で成立していない役を排除する。
候補ごとに、残りリールをどの順番・どの位相で押しても制限内に合法な完了形が残るかを再帰的に検証し、メモ化する。
合法な候補内で、成立役の入賞または持ち越しボーナス入賞を優先、同点は最小滑り。
リプレイは取りこぼさず、それ以外の小役・ボーナスは引き込み範囲外なら取りこぼす。
配列はこの制約を満たすよう設計したオリジナル。メーカー内部制御の複製ではない。
停止後も同じ帯・座標を保ち、全リールのアニメーション完了後に精算する。

## 保存と中断

`tsuduri_slot_a_type_v2` に抽選役・課金済みメダル・停止位置・ボーナス状態を保存。
レバー時に消費と抽選を保存し、各STOPで停止位置を保存する。
再開時は同じ役と停止済みリールから継続し、再抽選・二重消費しない。
保存できない端末では画面に警告する。旧v1遊技データは別キーで保持し、勝手に移行・削除しない。
リセットは二段階確認。BIG/REG演出確認は強制当選で、通常と同じ保存・精算を通る。

## 表示・未実装

ベクター図柄、入賞ライン、完全告知ランプ、ボーナス進捗、差枚グラフ、履歴、配列表示。
既存の5人の立ち絵で集合液晶・ボーナスカットインを構成。既存アイコンを256px WebP化して図柄・会話欄・筐体下パネルに使用（合計約76KB）。役と配列の意味は変えず、キャラ付きの7/BAR/小役図柄として表示する。
音声、BGM、リーチ目演出、告知タイミング振分は今後の制作対象。
回転速度は80rpm（21コマで1周750ms、28コマ/秒）。経過時間ベースで描画し、低フレームレートでも回転数を維持する。停止移動時間は距離÷回転速度を基準に16〜180ms。
参考：メーカー公開特許 https://patents.google.com/patent/JP2006087450A/ja （80rpm / 750ms / 21コマの記載）。現行全機種が厳密に同速という主張ではない。
目押し精度は端末の描画・入力遅延の影響を受ける。

## 筐体・小役モチーフ版

7は大きい赤金の図柄、BARは黒金の図柄として占有面積を拡大。リールの顔画像は外し、ボーナス図柄と小役をシルエットで区別する。キャラ画像は液晶・腰パネル・会話欄に使う。

既存の配列・抽選・保存・配当は維持し、描画だけを対応させる：
- 内部bell（8枚）→金色の丸型ベイトリール
- 内部replay→魚＋リプレイマーク
- 内部fish（6枚）→ジョイント式ビッグベイト
- 内部cherry（左リール2枚）→竿と赤ウキ

追加のスイカ役は新設していない。通常のスイカ相当の少なめの小役は、現在の6枚ビッグベイト役に対応する。

液晶演出は実際の抽選役と停止数に連動するCSS/SVGアニメーション。波・雲・魚影、金リールの光、ビッグベイトの泳ぎ、リプレイ魚、赤ウキの上下動とアタリ。小役演出はボーナス確定の意味を持たず、確定表示は既存の本当のボーナスフラグに従う。動画ファイルや追加通信を必要としない。動きを減らす設定では背景や小役アニメーションを停止。

クローム縁・液晶ガラス・リールベゼル・立体STOP・レバー・AUTO BET表示・投入口・スピーカー/受け皿風の装飾を追加。BET表示と投入口は装飾で、ゲーム操作は従来どおりレバーと3つのSTOP。

`node scripts/test-slot-artwork.cjs` で6種類の図柄、135コマの固有SVG ID、全小役/停止段階の演出、確定の誤表示防止を検証する。
